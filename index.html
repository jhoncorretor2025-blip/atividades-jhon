Como ativar o banco Supabase (uma única vez)

Crie um projeto gratuito em Supabase e abra SQL Editor. Execute o SQL abaixo para criar a tabela privada e as regras de acesso. Depois informe a URL e a chave publishable/anon do projeto.

create table if not exists public.activity_sync (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.activity_sync enable row level security;
create policy "Users manage own activity data"
on public.activity_sync for all
using (auth.uid() = user_id)
with check (auth.uid() = user_id);
grant select, insert, update, delete on public.activity_sync to authenticated;

Use uma senha forte. Nunca coloque a service_role key no navegador. O primeiro envio e a primeira restauração são manuais para evitar sobrescrever dados sem sua autorização.

Configure os dias do mês em que uma atividade fica visível. Atividades sem datas configuradas aparecem todos os dias.

Use intervalos separados por vírgula. Exemplo: 05-07, 12-13, 21-31. Para remover a regra e mostrar todos os dias, use “Mostrar todos os dias”.
